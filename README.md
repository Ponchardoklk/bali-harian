# Bali Harian

Asistente personal para el dia a dia: agenda, lista de la compra en Bali con los
nombres en indonesio, control de gastos en rupias y euros, y aviso de visado.

Se instala en el movil desde el navegador (Compartir -> Anadir a pantalla de
inicio) y funciona sin conexion.

**Todos los datos se guardan unicamente en el telefono.** No hay servidor, no hay
cuenta y nada se envia a ningun sitio.
